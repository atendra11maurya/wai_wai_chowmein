## ⚡ Seller Guide: Setting Up Free Admin Access in 2 Minutes

When you deploy this project to **Netlify** for your buyer, follow these 2 simple steps to enable the Admin Panel:

### Step 1: Deploy to Netlify
1. Push this project to GitHub.
2. Go to [Netlify.com](https://netlify.com) -> **Add new site** -> **Import from GitHub**.

### Step 2: Enable Netlify Identity & Git Gateway
1. In your Netlify Site Settings, go to **Site Settings -> Identity**.
2. Click **Enable Identity**.
3. Under **Registration Preferences**, set registration to **Invite Only** (so only your buyer can log in).
4. Scroll down to **Services -> Identity -> Enable Git Gateway**.
5. Go to the **Identity Tab** in Netlify dashboard -> Click **Invite Users** -> Type your buyer's email address.

🎉 **Done!** Your buyer receives an invitation email, sets their password, and can log into `theirwebsite.com/admin` anytime!
